## Shopify Flow とは・利用できるプランと基本概念

**Shopify Flow** は Shopify 管理画面上でコードを書かずにビジネス自動化ワークフローを構築できるノーコードツールです。<mark>利用できるのは **Advanced プランおよび Shopify Plus** のみで、Basic・Grow プランでは使用できません。</mark>Flow の基本構成要素は3つです。**トリガー**は自動化を開始するきっかけとなるイベントで、「注文が作成された」「在庫数が指定値以下になった」「顧客が作成された」など30種類以上が用意されています。**条件**はトリガーが発生した際に「どの場合に実行するか」を絞り込むフィルターで、「注文金額が5万円以上」「顧客タグに『member』が含まれる」「商品の在庫数が10未満」などの条件を AND / OR で組み合わせられます。**アクション**は条件を満たした場合に実行する処理で、「顧客にタグを追加する」「注文をアーカイブする」「Slack にメッセージを送る」「HTTP リクエストを送信する（外部 API 連携）」などが選べます。<u>Flow は一度設定すれば 24時間365日自動で動作し、手作業での繰り返し業務を排除することで運用コストを大幅に削減できます。</u>

> 💡 **Flow の画面を確認してみよう:** Advanced プランをお使いの場合、管理画面「**Flow（アプリ）**」を開き、テンプレートライブラリから「在庫が少ない商品のメール通知」などの既成テンプレートを確認してみましょう。トリガー→条件→アクションの流れが視覚的に確認できます。

## 実用的なフローの構築例

**在庫アラートフロー**は最も基本的なユースケースです。「在庫数が変更された」をトリガーとし、条件に「在庫数が5以下」を設定、アクションで「担当者にメールを送信」または「Slack チャンネルに通知」を組み合わせるだけで、売り切れ間際の商品を自動検知できます。<mark>**不正注文フラグフロー**は「注文が作成された」をトリガーとし、「Shopify の不正リスクスコアが High」かつ「注文金額が3万円以上」という条件でフラグを立て、担当者に確認メールを送るとともに注文に「要確認」タグを付与するフローです。これにより**高リスク注文を見落とすリスクが大幅に減ります。**</mark>**ロイヤルティタグ自動付与フロー**は顧客の累計購入額に応じてランクタグを自動管理します。「注文が支払い済みになった」をトリガーとし、「顧客の累計購入金額が5万円を超えた」という条件が満たされたら「silver-member」タグを追加し、以前の「standard」タグを削除するというフローです。<u>ランクに応じてメールマーケティングツール（Klaviyo など）がセグメントを自動更新し、専用オファーを配信する連携が実現できます。</u>

## フローのテストとトラブルシューティング

Flow では本番環境に影響を与えずにテストを行うことが重要です。<mark>フローの画面右上にある「**テスト**」ボタンを使うと、実際のトリガーを発生させずにサンプルデータでアクションが正しく動作するか確認できます。ただし**メール送信・外部 API 呼び出しなどは実際に実行されるため**、テスト時はテスト用のアドレスや Webhook.site などのテスト用 URL を使うようにしてください。</mark>フローを有効化した後は「**実行履歴**」タブから過去の実行ログを確認できます。エラーが発生した場合は赤いバッジで表示され、何のアクションがなぜ失敗したかの詳細が記録されています。よくある失敗原因として「参照している顧客タグの表記ゆれ（半角・全角・大文字小文字）」「外部 Webhook の URL が変更された」「HTTP アクションで認証ヘッダーが正しく設定されていない」などがあります。<u>複数のフローが同じトリガーで発火する場合は実行順序が保証されないため、互いに干渉しないよう設計し、本番運用前には必ずテスト注文を使って End-to-End での動作を確認してから有効化してください。</u>
