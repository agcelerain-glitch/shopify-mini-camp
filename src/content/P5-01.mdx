## Liquid とは何か

**Liquid** は Shopify 創業者の Tobi Lütke が Ruby で開発したオープンソースのテンプレート言語です。2006 年に Shopify のテーマエンジンとして生まれ、現在は GitHub・Zendesk・Salesforce Commerce Cloud など多くのプラットフォームで採用されています。<mark>Liquid の設計思想は「安全・読みやすい・柔軟」であり、テンプレートに任意のコードを埋め込めないよう意図的に機能が制限されています。これによって**マーチャントやデザイナーが誤ってサーバーに危険な処理を実行させるリスクを排除**しています。</mark>

Shopify テーマ開発において Liquid は HTML の中に埋め込む形で使います。構文は3種類に分類されます。**オブジェクト**（`{{ }}`）は変数の値を HTML に出力します。**タグ**（`{% %}`）は条件分岐・繰り返し・変数定義などのロジックを記述します。**フィルター**（`|`）はオブジェクトの値を変換・整形します。<u>たとえば `{{ product.price | money }}` と書くと、商品価格の数値を「¥3,980」のような通貨形式で出力できます。この3要素の組み合わせだけでほぼすべてのテーマ表示ロジックが実現できます。</u>

## Liquid オブジェクトとグローバル変数

Shopify が Liquid テンプレートに自動的に注入する変数を「**グローバルオブジェクト**」と呼びます。<mark>代表的なものは `product`（商品）、`collection`（コレクション）、`cart`（カート）、`customer`（顧客）、`shop`（ストア設定）、`request`（リクエスト情報）です。これらのオブジェクトは**各テンプレートの文脈に応じて自動で利用可能**になります。</mark>たとえば `templates/product.liquid` 内では `product` オブジェクトが使えますが、`templates/collection.liquid` 内では `collection` がメインオブジェクトになります。

`assign` タグで独自の変数を定義できます。`{% assign sale_price = product.price | times: 0.8 %}` のように書けば、定価の 80% をローカル変数として扱えます。`capture` タグを使うと複数行の HTML 文字列を変数に格納できます。また `{% for variant in product.variants %}` のように `for` タグを使えば配列型のオブジェクトを反復処理できます。`{% if product.available %}` のような条件分岐では `if / elsif / else / endif` を使います。<u>`unless` は `if not` の短縮形として役立ちます。これらのタグは必ずクロージングタグ（`endif`, `endfor`, `endunless` など）で閉じる必要があります。</u>

> 💡 **テーマエディタでコードを確認してみよう:** 管理画面「**オンラインストア → テーマ → コードを編集**」を開き、`templates/product.json` や `sections/main-product.liquid` を開いてみましょう。`{{ product.title }}` や `{{ product.price | money }}` がどこに書かれているか探してみてください。

## フィルターの活用と実践的なコード例

フィルターはパイプ記号（`|`）に続けて書き、複数のフィルターをチェーンできます。文字列系では `upcase`・`downcase`・`strip`・`split`・`replace`・`truncate` が頻繁に使われます。数値系では `plus`・`minus`・`times`・`divided_by`・`modulo`・`round`・`ceil`・`floor` が利用可能です。日付系では `date: "%Y年%m月%d日"` のようにフォーマット文字列を渡します。<mark>EC サイト特有のフィルターとして `money`（通貨記号付き価格）、`img_url`（画像 URL に幅・高さパラメーターを付加）、`asset_url`（テーマ assets フォルダのファイル URL 取得）が非常に重要です。</mark>

```liquid
{% comment %} 商品カードの典型的な書き方 {% endcomment %}
{% for product in collection.products %}
  <div class="product-card" data-product-id="{{ product.id }}">
    <a href="{{ product.url }}">
      <img
        src="{{ product.featured_image | img_url: '400x400', crop: 'center' }}"
        alt="{{ product.featured_image.alt | escape }}"
        loading="lazy"
      >
    </a>
    <h2>{{ product.title | truncate: 50 }}</h2>
    {% if product.compare_at_price > product.price %}
      <s>{{ product.compare_at_price | money }}</s>
      <span class="sale-price">{{ product.price | money }}</span>
    {% else %}
      <span>{{ product.price | money }}</span>
    {% endif %}
    {% unless product.available %}
      <span class="sold-out">売り切れ</span>
    {% endunless %}
  </div>
{% endfor %}
```

上のコードは「コレクション内の商品をループして、セール価格があれば取り消し線付きで定価を表示し、売り切れならバッジを表示する」という典型的なパターンです。<u>`escape` フィルターは XSS 攻撃を防ぐためにユーザー入力値を HTML エスケープするもので、`alt` 属性など外部から入る可能性のある値には必ず付けるべきです。</u>

## よくある質問

**Q. Liquid で JavaScript を直接書くことはできますか？**

できません。Liquid はサーバーサイドのテンプレート言語であり、ブラウザで実行される JavaScript とは完全に分離されています。ただし、`<script>` タグの中に Liquid を書いて Shopify のデータを JavaScript 変数に渡すことは可能です。たとえば `<script>var productId = {{ product.id }};</script>` のように書くと、レンダリング時に数値が埋め込まれ、フロントエンドの JavaScript から利用できるようになります。

**Q. Liquid のデバッグはどうやって行えばよいですか？**

<mark>最も手軽な方法は `{{ variable | json }}` フィルターを使ってオブジェクトの中身をそのまま画面に出力することです。`{{ product | json }}` と書けば**商品オブジェクトの全プロパティが JSON として表示**されます。</mark>また Shopify CLI（`shopify theme dev`）を使ってローカルでテーマをプレビューすると、変更を保存するたびにブラウザが自動リロードされるため、試行錯誤がしやすくなります。
