## 日本市場で重要な決済手段と選択基準

クレジットカードに加えて、日本の EC 市場では**スマホ決済**と**後払い（BNPL）** が急速に普及しています。

**追加で導入を検討すべき主な決済手段：**

- **PayPay** — 国内最大規模のスマホ決済。登録ユーザー 6,500 万人超（2026 年時点）
- **Paidy** — BNPL の国内最大手。翌月まとめ払い・3 回払いなどに対応
- その他：GMO イプシロン・KOMOJU・楽天ペイ・d払いなど

<mark>クレジットカードを持たない顧客・若年層・カード入力への抵抗感を持つ顧客を取り込む有効な手段です。</mark>

決済手段の多さは「**購入の摩擦を下げる**」直接的な施策であり、好みの決済方法が使えないことによる**カゴ落ち**を防ぐ効果があります。

**決済アプリを選ぶ際の判断基準：**

- 自社のターゲット顧客層が使っているか
- 手数料率（売上の何 % か）
- 導入の容易さ
- チェックアウトでの表示位置・見た目

<u>まず 1〜2 種類に絞って追加し、顧客からのフィードバックや注文データを見ながら拡張することをお勧めします。</u>あれもこれも追加するとチェックアウト画面が複雑になり逆効果になることもあります。

> 💡 **App Store を確認してみよう:** 管理画面「**アプリ → アプリストア**」を開き、「PayPay」または「Paidy」を検索してみましょう。各アプリの評価・レビュー・必要な事前準備を確認してから導入判断をするのがお勧めです。

## PayPay・Paidy のインストールと設定手順

**PayPay の設定：**

1. Shopify App Store で「PayPay」を検索してインストール
2. アプリを開き、PayPay for Business の加盟店登録で取得した以下を入力
   - API キー
   - シークレットキー
   - 加盟店 ID
3. テスト環境で動作確認 → 本番に切り替え

**Paidy の設定：**

<mark>Shopify App Store で「Paidy」を検索してインストールし、Paidy の加盟店ポータルで発行された API キーを入力します。</mark>どちらもテスト用クレデンシャルを使って先に動作確認を行ってから本番に切り替えることが推奨されています。

有効化後は「**設定 → 支払い → 支払い方法**」の一覧に PayPay・Paidy が表示され、顧客のチェックアウト画面にもボタンが追加されます。

**手数料の注意点：**

<u>サードパーティの決済アプリを使う場合は Shopify の「外部決済プロバイダー取引手数料」（0.5〜2%）が発生します。</u>Shopify Payments と組み合わせることで、Shopify Payments を経由するカード決済の取引手数料は免除され、PayPay・Paidy のみに外部取引手数料が適用されます。

## 決済構成の最適化と管理運用のポイント

**チェックアウトでの表示順序の設定**

「**設定 → 支払い**」の「支払い方法の並び替え」から変更できます。<mark>最も使われる決済方法を上位に表示することが転換率向上につながります。</mark>

**売上の確認方法**

| 決済手段 | 確認場所 |
|---|---|
| Shopify Payments | Shopify 管理画面に統合 |
| PayPay | PayPay for Business ダッシュボード |
| Paidy | 加盟店ポータル |

<u>Shopify の注文一覧と各決済プロバイダーの入金明細を月次で照合する習慣</u>をつけると会計処理がスムーズになります。

**返金（払い戻し）の処理**

管理画面「**注文 → 該当注文 → 返金**」から行います。PayPay・Paidy では Shopify 上での返金操作が各プロバイダーの API を通じて自動実行される場合と、プロバイダー側で手動対応が必要な場合があります。カスタマーサポートに備えてトラブル事例と解決手順を事前に把握しておくことが重要です。

> 💡 **支払い方法の順序を確認してみよう:** 決済アプリを追加したら「**設定 → 支払い**」を開き、チェックアウト画面での表示順序を確認・変更してみましょう。実際にストアのチェックアウトページにアクセスして、顧客目線で使いやすい順番になっているかも確認してください。
