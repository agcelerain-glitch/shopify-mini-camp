## Shopify 商品 CSV の構造と必須フィールド

数十〜数百件の商品を一度に登録・更新する場合、1件ずつ手動入力するよりも **CSV（カンマ区切り値）ファイル** を使った一括インポートが圧倒的に効率的です。

<mark>まず管理画面「**商品 → エクスポート**」から既存商品または空のサンプルを CSV でダウンロードし、列構成を確認してください。Shopify の商品 CSV は「エクスポートでサンプル取得 → Excel・Google スプレッドシートで編集 → インポート」というフローで使います。</mark>

**主要な列の一覧：**

| 列名 | 説明 |
|---|---|
| **Handle** | URL スラッグ（商品ごとに一意。バリアントを持つ商品は同じハンドルを複数行に書く） |
| **Title** | 商品タイトル（**必須**） |
| **Body** | 説明文（HTML 可） |
| **Vendor** | ブランド名 |
| **Tags** | タグ（カンマ区切り） |
| **Variant SKU** | SKU コード |
| **Variant Price** | 販売価格（税抜き数値のみ。¥や,は入れない） |
| **Variant Compare At Price** | 比較価格（定価） |
| **Variant Quantity** | 在庫数 |
| **Image Src** | 画像の URL（https:// で始まる公開 URL） |
| **Image Alt Text** | 画像の alt テキスト |

**バリアントがある商品の行構成：**

同じ Handle を持つ行が複数ある場合、Shopify はそれをバリアントとして扱います。

<u>1行目に商品共通情報（Title・Body・Vendor など）を書き、2行目以降はハンドルとバリアント情報（SKU・Price・Quantity）のみ書きます。この構造を誤ると重複商品が作成されたりバリアントが別商品として登録されたりするため、サンプル CSV でよく確認してから編集してください。</u>

> 💡 **サンプル CSV を確認してみよう:** 管理画面「**商品 → エクスポート**」から「現在のページにある商品」を CSV でエクスポートしてみましょう。Excel または Google スプレッドシートで開き、Handle・Title・Variant Price などの列構成と、複数バリアントの商品がどのように複数行で表現されているかを確認してください。

## 一括インポートと在庫更新の実践手順

**インポートの実行手順：**

1. 管理画面「**商品 → インポート**」を開く
2. CSV ファイルをアップロード
3. 「**既存の商品と一致するものを上書きする**」オプションを確認
   - 新規商品追加 → オフ
   - 既存商品の更新（価格変更・在庫更新） → オン
4. 「**プレビュー**」で列マッピングと内容を確認してからインポート実行

<mark>特に日本語を含む CSV は **UTF-8（BOM 付き）** でエンコードして保存することが文字化けを防ぐ重要なポイントです。Excel で保存する場合は「名前を付けて保存 → ファイルの種類を "CSV UTF-8（コンマ区切り）"」を選択してください。</mark>

**在庫数の一括更新（在庫 CSV）：**

商品情報ではなく在庫数だけを更新したい場合は「在庫 CSV」が効率的です。

1. 管理画面「**在庫 → エクスポート**」から SKU・ロケーション別在庫数が含まれた CSV を取得
2. 在庫数を修正
3. インポートで一括更新

大規模セール前の在庫確保や入荷時の在庫反映に特に便利です。

## インポートエラーの原因特定と修正

インポート時にエラーが発生した場合は「**エラーログをダウンロード**」から詳細を確認します。

**よくあるエラーと原因：**

| エラー | 原因 | 対処 |
|---|---|---|
| 重複ハンドル | 異なる商品が同じハンドルを持っている | ハンドルを一意に修正する |
| 画像 URL が無効 | URL がパブリックにアクセスできない | 公開URLに変更する |
| 価格の形式エラー | ¥記号・カンマが含まれている（例：¥3,980）| 数値のみに修正（例：3980）|
| 文字化け | UTF-8 BOM なし・Excel が Shift-JIS で保存 | UTF-8（BOM付き）で再保存 |

<mark>Shopify は CSV インポート時に画像 URL を取得して自サーバーにコピーするため、**インポート実行時点でその URL がパブリックにアクセス可能**でないと失敗します。Google Drive の共有リンクではなく、Dropbox の直接リンク・S3 の公開 URL などを使ってください。</mark>

**再インポート時の注意点：**

<u>エラー修正後の再インポートでは「上書きオプション」の設定を誤ると意図しない商品が書き換わるため、インポート前の設定確認を毎回必ず行う習慣</u>をつけてください。

> 💡 **CSV インポートを試してみよう:** まず「**商品 → エクスポート**」でサンプル CSV をダウンロードし、1商品のデータを1行分コピーして別の商品データに書き換えましょう。Handle を新しい一意の文字列に変更し、「**商品 → インポート**」でアップロード。プレビューを確認して問題なければインポートし、管理画面に新商品が追加されているか確認してください。
