## Shopify が送信する通知メールの種類

Shopify は注文・配送・支払い・アカウントなどのライフサイクルイベントに応じて自動的に**通知メール**を送信します。管理画面「**設定 → 通知**」から全通知の一覧と個別テンプレートの編集が行えます。

**主要な通知メール：**

| 種類 | タイミング |
|---|---|
| 注文確認（Order Confirmation） | 注文完了直後に顧客へ送信される最重要メール |
| 発送通知（Shipping Confirmation） | フルフィルメント完了・追跡番号登録時に自動送信 |
| 返金確認（Refund Notification） | 返金処理完了後に送信 |
| カゴ落ちメール（Abandoned Checkout） | チェックアウトを途中放置した顧客への自動リマインド |

<mark>Shopify のデフォルトの通知メールテンプレートは**英語**で書かれているため、日本語向けストアではすべてのテンプレートを日本語に翻訳・カスタマイズすることが必要です。</mark>

テンプレートは **Liquid**（Shopify のテンプレート言語）で書かれており、`{{ order.name }}` や `{{ customer.first_name }}` などの変数が注文・顧客情報の動的挿入に使われています。

<u>変数部分（`{{ }}` で囲まれた部分）を触らずにテキスト部分だけを日本語に書き換えることは難しくありません。</u>

> 💡 **通知メールを確認してみよう:** 「**設定 → 通知**」を開き、「注文確認（Order confirmation）」をクリックして「**プレビューメールを送信**」を実行しましょう。自分のメールアドレスに届く英語の通知メールを見て、どこを日本語に変えるべきか確認してみてください。

## 通知メールテンプレートの編集方法

「**設定 → 通知 → 注文確認（Order confirmation）**」を開くと HTML テンプレートのエディタが表示されます。

**テンプレート編集の基本手順：**

1. 英語テキスト部分（`<p>` タグや `<h2>` タグに囲まれたテキスト）を日本語に翻訳する
2. `{{ variable }}` 形式の Liquid 変数はそのまま残す
3. **件名（Subject）を日本語に変更する**

件名の例：`Order confirmation` → `ご注文ありがとうございます — {{ order.name }}`

**差出人メールアドレスの設定：**

<mark>「**設定 → 一般 → カスタマーメールアドレス**」で設定したアドレスが使われます。**独自ドメインのメールアドレスを設定することでブランドの信頼性が上がります**（例：`info@yourbrand.com`）。</mark>

独自ドメインを差出人にする場合は DKIM・SPF の DNS レコード設定が必要になります（「設定 → ドメイン → メール転送」で確認）。

**カゴ落ちメールの設定：**

「**設定 → 通知 → カゴ落ち**」から時間遅延（1時間後・6時間後・24時間後）を選んで有効化できます。

<u>このメール1本で売上の数%〜十数%を回収できる効果的な施策です。開設直後から設定しておくことをお勧めします。</u>

> 💡 **件名を日本語に変更してみよう:** 「**設定 → 通知 → 注文確認**」を開き、Subject フィールドを `ご注文ありがとうございます — {{ order.name }}` に変更して保存しましょう。「プレビューメールを送信」で日本語件名のメールが届くことを確認してください。

## メールのブランドトーンと効果的な文体設計

通知メールは単なる「情報伝達ツール」ではなく、顧客との**ブランドコミュニケーション**の機会です。

<mark>**注文確認メールは顧客が最も高い関心を持って読むメールで、開封率は通常のメルマガの 5〜10 倍に達することもあります。**</mark>

**文体の選択：**

ブランドのキャラクターに合わせて統一します。

- 丁寧語（です・ます調）— フォーマルなブランドに
- フレンドリーな丁寧語（届くのを楽しみにしていてください！）— カジュアルなブランドに

**効果的な通知メールのポイント：**

- 件名は簡潔に・注文番号を含める
- 最初の一文でお礼を述べる
- 注文内容のサマリー（商品名・数量・金額）を明確に表示する
- 次のステップ（発送予定日・問い合わせ方法）を案内する

テンプレートのカラーは HTML の `background-color` や `color` プロパティを直接編集することで調整できます。

すべてのテンプレート編集後は複数の端末（PC・スマートフォン）・複数のメールクライアント（Gmail・Outlook・Apple Mail）でプレビュー送信して、<u>表示崩れがないことを確認</u>してください。

> 💡 **本文を日本語に書き換えてみよう:** 注文確認メールのテンプレートを開き、英語本文の `Thank you for your purchase!` の部分を `この度はご注文いただきありがとうございます！` に変更してみましょう。`{{ variable }}` 変数はそのまま残し、テキスト部分だけを日本語に置き換えてください。保存後は必ずプレビュー送信で確認することを忘れずに。
