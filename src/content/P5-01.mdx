## Liquid とは何か

**Liquid** は Shopify 創業者の Tobi Lütke が Ruby で開発したオープンソースのテンプレート言語です。2006 年に Shopify のテーマエンジンとして生まれ、現在は GitHub・Zendesk など多くのプラットフォームで採用されています。

<mark>Liquid の設計思想は「安全・読みやすい・柔軟」であり、テンプレートに任意のコードを埋め込めないよう意図的に機能が制限されています。これによって**マーチャントやデザイナーが誤ってサーバーに危険な処理を実行させるリスクを排除**しています。</mark>

**Liquid の3つの構文要素：**

| 構文 | 記法 | 用途 | 例 |
|---|---|---|---|
| **オブジェクト** | `{{ }}` | 変数の値を HTML に出力する | `{{ product.title }}` |
| **タグ** | `{% %}` | 条件分岐・繰り返し・変数定義などのロジック | `{% if product.available %}` |
| **フィルター** | `\|` | オブジェクトの値を変換・整形する | `{{ product.price \| money }}` |

<u>たとえば `{{ product.price | money }}` と書くと、商品価格の数値を「¥3,980」のような通貨形式で出力できます。この3要素の組み合わせだけでほぼすべてのテーマ表示ロジックが実現できます。</u>

> 💡 **テーマエディタでコードを確認してみよう:** 管理画面「**オンラインストア → テーマ → コードを編集**」を開き、`sections/main-product.liquid` を開いてみましょう。`{{ product.title }}` や `{{ product.price | money }}` がどこに書かれているか探してみてください。

## Liquid オブジェクトとグローバル変数

Shopify が Liquid テンプレートに自動的に注入する変数を「**グローバルオブジェクト**」と呼びます。

<mark>代表的なグローバルオブジェクトは各テンプレートの文脈に応じて**自動で利用可能**になります：</mark>

| オブジェクト | 利用できるページ | 主な用途 |
|---|---|---|
| `product` | 商品詳細（product.liquid） | タイトル・価格・画像・バリアント |
| `collection` | コレクション一覧 | コレクション内の商品リスト |
| `cart` | カートページ | カート内商品・合計金額 |
| `customer` | マイアカウントページ | 顧客名・注文履歴 |
| `shop` | 全ページ | ストア名・通貨・設定 |

**変数定義と制御構文：**

- `assign` タグで独自の変数を定義：`{% assign sale_price = product.price | times: 0.8 %}`
- `capture` タグで複数行の HTML を変数に格納
- `{% for variant in product.variants %}` で配列を反復処理
- `{% if product.available %}` で条件分岐（`unless` は `if not` の短縮形）

<u>タグは必ずクロージングタグ（`endif`, `endfor`, `endunless` など）で閉じる必要があります。</u>

> 💡 **グローバルオブジェクトの中身を確認してみよう:** 商品詳細ページのテーマファイルを開いて `{{ product | json }}` を一時的に追加し、ブラウザで商品ページを確認してみましょう。商品オブジェクトの全プロパティが JSON として画面に表示されます。確認後は必ず削除してください。

## フィルターの活用と実践的なコード例

フィルターはパイプ記号（`|`）に続けて書き、複数のフィルターをチェーンできます。

**よく使うフィルターの分類：**

| 種類 | フィルター例 | 用途 |
|---|---|---|
| 文字列系 | `upcase` `downcase` `truncate` `replace` | 大文字変換・切り詰め |
| 数値系 | `plus` `times` `divided_by` `round` | 四則演算・丸め |
| 日付系 | `date: "%Y年%m月%d日"` | 日付フォーマット |
| EC 特有 | `money` `img_url` `asset_url` | 価格表示・画像 URL |

<mark>EC サイト特有のフィルターとして `money`（通貨記号付き価格）、`img_url`（画像 URL に幅・高さパラメーターを付加）、`asset_url`（テーマ assets フォルダのファイル URL 取得）が非常に重要です。</mark>

```liquid
{% comment %} 商品カードの典型的な書き方 {% endcomment %}
{% for product in collection.products %}
  <div class="product-card" data-product-id="{{ product.id }}">
    <a href="{{ product.url }}">
      <img
        src="{{ product.featured_image | img_url: '400x400', crop: 'center' }}"
        alt="{{ product.featured_image.alt | escape }}"
        loading="lazy"
      >
    </a>
    <h2>{{ product.title | truncate: 50 }}</h2>
    {% if product.compare_at_price > product.price %}
      <s>{{ product.compare_at_price | money }}</s>
      <span class="sale-price">{{ product.price | money }}</span>
    {% else %}
      <span>{{ product.price | money }}</span>
    {% endif %}
    {% unless product.available %}
      <span class="sold-out">売り切れ</span>
    {% endunless %}
  </div>
{% endfor %}
```

<u>`escape` フィルターは XSS 攻撃を防ぐためにユーザー入力値を HTML エスケープするもので、`alt` 属性など外部から入る可能性のある値には必ず付けるべきです。</u>

> 💡 **コレクションページでフィルターを試してみよう:** テーマのコレクションセクションを開き、`{{ product.price | money }}` の出力を確認しましょう。次に `{{ product.created_at | date: "%Y年%m月%d日" }}` を試して日付フォーマットの変換を確認してください。

## よくある質問

**Q. Liquid で JavaScript を直接書くことはできますか？**

できません。Liquid はサーバーサイドのテンプレート言語であり、ブラウザで実行される JavaScript とは分離されています。ただし `<script>` タグの中に Liquid を書いて Shopify のデータを JavaScript 変数に渡すことは可能です。

```liquid
<script>var productId = {{ product.id }};</script>
```

**Q. Liquid のデバッグはどうやって行えばよいですか？**

<mark>最も手軽な方法は `{{ variable | json }}` フィルターを使ってオブジェクトの中身をそのまま画面に出力することです。`{{ product | json }}` と書けば**商品オブジェクトの全プロパティが JSON として表示**されます。</mark>また Shopify CLI（`shopify theme dev`）を使ってローカルでテーマをプレビューすると、変更を保存するたびにブラウザが自動リロードされます。
