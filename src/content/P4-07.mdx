## ページ速度が EC 売上に直結する理由

<mark>Google の調査（2023年）では「**モバイルページの読み込みが1秒遅くなるたびにコンバージョン率は約 20% 低下する**」というデータが示されています。ページ速度は単なる技術的な問題ではなく、直接売上に影響するビジネス指標です。</mark>

また Google は **Core Web Vitals（CWV）** を検索順位の評価要素に採用しており、ページ速度が低いサイトは SEO 的にも不利になります。

**Core Web Vitals の3指標：**

| 指標 | 意味 | 目標値 |
|---|---|---|
| **LCP（Largest Contentful Paint）** | 最も大きなコンテンツの表示完了時間 | **2.5秒以下** |
| **INP（Interaction to Next Paint）** | ユーザー操作への応答速度 | **200ms 以下** |
| **CLS（Cumulative Layout Shift）** | レイアウトのズレの度合い | **0.1以下** |

**速度測定ツール：**

- **Google PageSpeed Insights**（無料・URL を入力するだけ）
- **GTmetrix**（詳細なウォーターフォール分析）
- Shopify 管理画面「**オンラインストア → テーマ → … → スピードレポート**」（同業他社との比較スコアも確認可）

<u>まず現状のスコアを計測してから改善を始めることが重要です。</u>

> 💡 **PageSpeed Insights でスコアを確認してみよう:** Google 検索で「PageSpeed Insights」を開き、自分のストアの URL を入力してモバイルスコアを確認しましょう。「診断」セクションに表示される改善提案のうち、上位3つを確認してください。

## Shopify テーマの速度改善：画像・アプリ・JavaScript

**① 画像の最適化（最も効果が大きい）**

<mark>商品画像は **2048px × 2048px 以内・ファイルサイズ 1MB 以下**を目安とし、バナー画像は横幅 1440px で WebP 形式が理想です。</mark>

Shopify は画像を CDN 経由で配信し WebP への自動変換も行いますが、アップロード前の元画像が大きすぎると効果が薄れます。

Liquid テンプレートでの最適化：

- `<img>` タグに `loading="lazy"` を設定 → スクロール前の先読みを防ぐ
- `width`・`height` 属性を明示 → CLS（レイアウトズレ）を防止

**② アプリの精査**

インストールしたまま使っていないアプリは削除してください。

<mark>Shopify アプリはアンインストール後もテーマファイルに JavaScript やスタイルシートのコードを残すことがあり、**不要なスクリプトがページ読み込みを遅らせます。**</mark>

ブラウザの開発者ツールの「ネットワーク」タブで読み込まれているスクリプト一覧を確認し、不要なものを `theme.liquid` から手動で削除することが必要な場合があります。

**③ JavaScript の最適化**

<u>テーマ内の `<script>` タグに `defer` または `async` 属性を付けることで、JavaScript の読み込みが HTML のパースをブロックしなくなります。</u>

> 💡 **不要なアプリを確認してみよう:** Shopify 管理画面「**アプリ**」を開き、最後に使った日を確認して6か月以上使っていないアプリをリストアップしましょう。削除後は PageSpeed Insights でスコアを再測定して改善幅を確認してください。

## Core Web Vitals の改善と継続モニタリング

**LCP（最大コンテンツの表示）の改善：**

ファーストビューに表示される最も大きい要素（多くの場合はヒーロー画像またはテキスト）の表示を優先させます。

- ヒーロー画像には `loading="lazy"` を付けず、代わりに `fetchpriority="high"` を付ける
- フォントに `font-display: swap` を CSS に設定して、カスタムフォント読み込み中もシステムフォントで表示させる

<mark>フォントの読み込み待ちが LCP の原因になっているケースは多いため、`font-display: swap` の設定は必ず行いましょう。</mark>

**CLS（レイアウトズレ）の改善：**

主な原因と対処：

| 原因 | 対処 |
|---|---|
| 画像に width / height 属性が指定されていない | 全 `<img>` タグにサイズを明示 |
| Web フォントの読み込み完了で文字幅が変わる | `font-display: swap` の設定 |
| 広告や動的コンテンツが後から挿入される | 表示領域をあらかじめ確保する |

**継続モニタリング：**

<u>改善後は Google Search Console の「ウェブに関する主な指標」レポートで実際のユーザーデータ（フィールドデータ）を定期的に確認します。PageSpeed Insights の「ラボデータ」は実際のユーザー環境と異なることがあるため、Search Console のフィールドデータを本番環境での最終評価として使うことが適切です。</u>

> 💡 **Search Console でフィールドデータを確認してみよう:** Google Search Console（search.google.com/search-console）を開き、「ウェブに関する主な指標」レポートを確認しましょう。「不良 URL」や「改善が必要な URL」がリストアップされていれば、上位のページから優先的に対処してください。
