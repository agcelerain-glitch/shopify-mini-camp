## カスタムドメインの選び方と取得

Shopify アカウント作成時に発行される `.myshopify.com` のサブドメイン URL はあくまで仮の URL です。<mark>**ブランドとして信頼性・覚えやすさ・SEO の観点から、独自ドメイン（例：`www.yourbrand.com`）の取得と設定が開店前の重要ステップです。**</mark>

**ドメイン取得の方法は2種類あります。**

**Shopify から直接購入する**

管理画面「**オンラインストア → ドメイン → ドメインを購入**」から検索・購入まで完結します。DNS 設定が自動で完了するため手間が最も少ないですが、外部レジストラより価格が割高なことがあります。

**外部レジストラで取得して接続する**

お名前.com・ムームードメイン・Cloudflare Registrar などを使います。価格・管理の自由度が高い一方、自分で DNS レコードを設定する必要があります。

**ドメイン名の選定基準：**

- ブランド名に近い・短くて覚えやすい
- スペルが直感的・発音しやすい
- `.com`（汎用・信頼性高）、`.jp`（日本向けに明確）、`.co.jp`（法人限定・信頼性高）

> 💡 **ドメインを購入してみよう:** 管理画面「**オンラインストア → ドメイン**」を開いて「ドメインを購入」または「既存のドメインを接続」ボタンを確認しましょう。Shopify から直接購入する場合はここから完結します。

## DNS 設定と Shopify へのドメイン接続

外部レジストラで取得したドメインを Shopify に接続するには **DNS（Domain Name System）レコード**の設定が必要です。

**操作手順（3ステップ）**

1. Shopify 管理画面「**オンラインストア → ドメイン → 既存のドメインを接続**」からドメイン名を入力し、表示される設定値を控える
2. 外部レジストラの管理画面にログインし、DNS 設定（ゾーン設定）で以下のレコードを追加・変更する
3. Shopify 管理画面でステータスが「**接続済み**」になったら「プライマリドメインに設定」する

**設定するレコードの値：**

<mark>
- **A レコード**：`@`（ルートドメイン）→ `23.227.38.65`
- **CNAME レコード**：`www` → `shops.myshopify.com`
</mark>

設定後は DNS の反映に **24〜72 時間**かかる場合があります。[whatsmydns.net](https://www.whatsmydns.net/) などのウェブツールでレコードが正しく伝搬しているか確認できます。

> 💡 **DNS 設定をやってみよう:** 外部レジストラで購入済みのドメインがあれば、その管理画面の「DNS 設定」を開いてみましょう。A レコードに `23.227.38.65`、CNAME レコードに `shops.myshopify.com` を設定します。

## SSL 証明書と www リダイレクトの確認

ドメインが正しく接続されると、Shopify は自動的に **Let's Encrypt** による **SSL 証明書（HTTPS）** を発行します。発行には数分〜数時間かかる場合があります。

<mark>HTTPS は現代の EC サイトでは必須で、顧客がクレジットカード情報を入力する際のセキュリティを担保するだけでなく、Google の検索ランキング評価要因にもなっています。</mark>

Shopify が自動で行う処理：

- `http://` でのアクセスを `https://` に自動リダイレクト
- `yourdomain.com`（www なし）を `www.yourdomain.com` に自動転送

**ドメイン設定後の確認チェックリスト：**

- [ ] `www` ありでアクセスできるか
- [ ] `www` なしでアクセスして自動転送されるか
- [ ] ブラウザの鍵アイコンが表示されているか（HTTPS 有効）
- [ ] 旧 `.myshopify.com` の URL から新ドメインに転送されるか

<u>ドメインを後から変更することはできますが、SEO の被リンク・ブックマーク・SNS プロフィールの URL をすべて変更する必要が生じます。初期段階で長期的に使えるドメインを選ぶことが重要です。</u>

> 💡 **接続を確認してみよう:** ドメイン接続後、ブラウザで `http://` から始まる URL と `https://` から始まる URL の両方を入力してみましょう。どちらも最終的に `https://www.yourdomain.com` に自動転送されれば設定は完了です。
