## Shopify トライアルの開始とアカウント作成

Shopify は公式サイト（shopify.com）から **3日間の無料トライアル**を申し込めます。<mark>メールアドレスを入力するだけでアカウントが作成でき、クレジットカード情報の入力は不要です。</mark>

トライアル期間中はすべての基本機能が使え、実際にストアを構築して動作を確認できます。終了後はプランを選択して有料移行するか、アカウントを休止します。

アカウント作成時に「ビジネスの目的」「販売経験」などを聞かれますが、オンボーディングのカスタマイズに使われるだけで後から変更できます。

**ストア名について注意が必要です。**

- <u>`.myshopify.com` の前の部分（例：`your-store.myshopify.com`）はアカウント作成後に変更できません</u>
- ブランド名に近い名前を入力することをお勧めします
- 顧客向けの表示名は後から管理画面で変更可能です

アカウント作成後は管理画面（`your-store.myshopify.com/admin`）にアクセスできます。Shopify はすべてのストアに **SSL 証明書（HTTPS）** を自動発行するため、セキュリティ面の追加作業は不要です。

> 💡 **アカウントを作成してみよう:** [shopify.com/jp](https://www.shopify.com/jp) にアクセスし、「無料で試す」ボタンからトライアルを開始しましょう。ストア名は慎重に決めてください。

## 管理画面の構造と主要セクションのツアー

Shopify の管理画面は左側サイドバーにナビゲーションが配置されています。

| セクション | 主な用途 |
|---|---|
| ホーム | 売上・注文数・訪問者数の概要、セットアップチェックリスト |
| 注文 | 受注一覧・フルフィルメント・返金の管理 |
| 商品 | 商品・コレクション・在庫・仕入れ注文の管理 |
| 顧客 | 顧客情報・セグメントの管理 |
| 分析情報 | 売上・トラフィック・マーケティングのレポート |
| マーケティング | キャンペーン・オートメーション・割引の設定 |
| オンラインストア | テーマ・ブログ・ページ・ナビゲーション・ドメインの管理 |
| アプリ | インストール済みアプリと App Store へのアクセス |

<mark>**「設定」は支払い・配送・税金・通知・ユーザー権限などを管理する最重要セクションです。** EC 運営の根幹をここで決定します。</mark>

管理画面右上の「ストアを表示」ボタンから実際の顧客目線でストアフロントを確認できます。スタッフを追加する場合は「設定 → ユーザーと権限」から行い、スタッフごとにアクセスできるセクションを制限できます。

> 💡 **管理画面を一周してみよう:** ホーム・注文・商品・設定の各セクションをクリックして、どんな情報が管理できるか確認しましょう。「設定」はサブメニューが多いので、眺めるだけでも全体像が掴めます。

## トライアル期間中の優先設定チェックリスト

3日間のトライアルを最大活用するために、設定すべき優先項目です。

**最優先（まず必ずやること）**

- 基本情報の設定（店舗名・住所・通貨・言語）
- テーマのインストールと簡単なカスタマイズ
- 商品を最低1件テスト登録して表示確認
- 設定 → 支払いでサポートされる決済方法を確認

**次に優先（余裕があれば）**

- 配送設定（国内送料の大枠）
- 税設定の確認（消費税 10%）
- メールアドレス・通知メールの送信元確認

テーマ・決済・配送・税の4点が揃えばテスト注文を実行できます。

**テスト決済の方法：** 「設定 → 支払い → Bogus Gateway」でテストモードを有効にし、テスト用カード番号 `4242 4242 4242 4242`（有効期限は未来日付、CVV は任意3桁）で注文フローを一通り体験できます。

確認すべき項目：
- 注文確認メール・発送通知メールが正しく届くか
- 在庫が正しく減算されるか
- 管理画面で注文が確認できるか

> 💡 **テスト注文を試してみよう:** 「**設定 → 支払い**」でテストモードを有効にし、テスト用カード番号で実際に注文を完了させてみましょう。メールが届くか・管理画面に注文が表示されるかを確認することで、本番公開前の動作確認が完了します。
