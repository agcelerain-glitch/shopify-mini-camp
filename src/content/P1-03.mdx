## カスタムドメインの選び方と取得

Shopify アカウント作成時に発行される `.myshopify.com` のサブドメイン URL はあくまで仮の URL です。<mark>**ブランドとして信頼性・覚えやすさ・SEO の観点から、独自ドメイン（例：`www.yourbrand.com`）の取得と設定が開店前の重要ステップです。**</mark>ドメインは Shopify から直接購入する方法（管理画面「**オンラインストア → ドメイン → ドメインを購入**」）と、外部レジストラ（お名前.com・ムームードメイン・Cloudflare Registrar など）から取得して接続する方法の2種類あります。**Shopify から直接購入**する場合は DNS 設定が自動で完了するため手間が最も少ないですが、価格が外部より割高なことがあります。**外部レジストラで取得**する場合は自分で DNS レコードを設定する必要がありますが、価格・管理の自由度が高いです。ドメイン名の選定では「**ブランド名に近い・短くて覚えやすい・スペルが直感的・発音しやすい**」を基準にします。`.com` が最も汎用的で信頼性が高く、次点で `.jp`（日本向けに明確）、`.co.jp`（法人限定だが信頼性が高い）が選ばれます。

> 💡 **ドメインを購入してみよう:** 管理画面「**オンラインストア → ドメイン**」を開いて「ドメインを購入」または「既存のドメインを接続」ボタンを確認しましょう。Shopify から直接購入する場合はここから検索・購入まで完結します。

## DNS 設定と Shopify へのドメイン接続

外部レジストラで取得したドメインを Shopify に接続するには **DNS（Domain Name System）レコード**の設定が必要です。操作は3ステップです。まず Shopify 管理画面「**オンラインストア → ドメイン → 既存のドメインを接続**」からドメイン名を入力し、表示される設定値（IP アドレスと CNAME の値）を控えます。次に外部レジストラの管理画面にログインし、DNS 設定（ゾーン設定）で以下のレコードを追加・変更します。<mark>**A レコード：`@`（ルートドメイン）→ Shopify の指定 IP アドレス `23.227.38.65`　／　CNAME レコード：`www` → `shops.myshopify.com`**</mark>を設定します。設定後は DNS の反映に **24〜72 時間**かかる場合があります。反映が完了すると Shopify 管理画面のドメイン一覧でステータスが「**接続済み**」になります。最後に「**プライマリドメインに設定**」で `www.yourdomain.com` を主ドメインとして設定します。DNS ルックアップツール（[whatsmydns.net](https://www.whatsmydns.net/) などのウェブツール）でレコードが正しく伝搬しているか確認できます。

> 💡 **DNS 設定をやってみよう:** 外部レジストラで購入済みのドメインがあれば、その管理画面の「DNS 設定」または「ゾーン設定」を開いてみましょう。A レコードと CNAME レコードの設定欄を確認し、Shopify の指定値（`23.227.38.65` と `shops.myshopify.com`）に更新します。設定後は whatsmydns.net で伝搬状況を確認できます。

## SSL 証明書と www リダイレクトの確認

ドメインが正しく接続されると、Shopify は自動的に **Let's Encrypt** による **SSL 証明書（HTTPS）** を発行します。発行には数分〜数時間かかる場合があります。ブラウザのアドレスバーに **鍵アイコン**が表示されれば HTTPS が有効な証明です。<mark>HTTPS は現代の EC サイトでは必須で、顧客がクレジットカード情報を入力する際のセキュリティを担保するだけでなく、Google の検索ランキング評価要因にもなっています。</mark>Shopify は `http://` でのアクセスを自動的に `https://` にリダイレクトするため、手動での設定は不要です。また `yourdomain.com`（www なし）へのアクセスも自動的に `www.yourdomain.com` にリダイレクトされます。ドメイン設定後に確認すべき項目として「<u>www あり・なし両方でアクセスできるか</u>」「<u>HTTPS でアクセスできるか</u>」「<u>旧 `.myshopify.com` の URL から新ドメインに転送されているか</u>」の3点をブラウザで確認してください。ドメインを後から変更することはできますが、SEO の被リンク・ブックマーク・SNS プロフィールの URL をすべて変更する必要が生じるため、<u>初期段階で長期的に使えるドメインを選ぶことが重要</u>です。

> 💡 **接続を確認してみよう:** ドメイン接続後、ブラウザで `http://` から始まる URL と `https://` から始まる URL の両方を入力してみましょう。どちらも最終的に `https://www.yourdomain.com` に自動転送されれば SSL とリダイレクトの設定は完了です。
