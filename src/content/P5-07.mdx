## Shopify Plus とは・どんな事業者に必要か

**Shopify Plus** は Shopify の Enterprise プランで、月額約 $2,500〜（または月次売上の 0.25%、どちらか高い方）から利用できます。

<mark>**Plus でなければできない主要機能：**</mark>

| 機能 | 内容 |
|---|---|
| Checkout Extensibility | チェックアウト画面のカスタム UI・ロジック実装 |
| B2B チャネル | 企業間取引のカンパニー管理・専用価格リスト |
| Wholesale Channel | B2B 専用のパスワード付きストアフロント |
| Multistore（Organization 管理） | 複数ストアの一元管理 |
| 高度な Shopify Flow | 外部 API 連携・高度なトリガー・アクション |
| 専任サポートマネージャー | 導入支援・テクニカルサポート |

**Plus が必要になる典型的なシナリオ：**

- 月商 3,000 万円以上のブランド
- 大量の注文処理が必要なフラッシュセール事業者
- B2B（企業間取引）を行うメーカー・卸売業者
- 複数ブランドを運営するグループ企業

<u>既存の Advanced プランでの月商が 1,000 万円を超えてきたあたりで、トランザクション手数料の削減効果も含めて Plus への移行コスパを計算するのが現実的なタイミングです。</u>

> 💡 **Plus への移行タイミングを試算してみよう:** 自社の月商と Shopify Payments のトランザクション手数料率から「月間の手数料総額」を計算しましょう。Advanced → Plus でトランザクション手数料が削減される金額と Plus の追加費用を比較することで、移行の損益分岐点が見えてきます。

## Checkout Extensibility：チェックアウトページの安全なカスタマイズ

<mark>**2024年末をもって旧来の `checkout.liquid`**（Liquid テンプレートによるチェックアウト改造）は廃止となりました。代替として Shopify が提供するのが **Checkout UI Extensions** と **Shopify Functions** を組み合わせた **Checkout Extensibility** です。カスタマイズ部分だけが独立したサンドボックス（拡張領域）に描画されるため、Shopify がアップデートしてもカスタマイズが壊れません。</mark>

**利用できる拡張ポイント（一部）：**

| 拡張ポイント | 表示場所 |
|---|---|
| `purchase.checkout.block.render` | チェックアウト内の任意の位置 |
| `purchase.checkout.shipping-option-list.render-after` | 配送方法の直後 |
| `purchase.checkout.payment-method-list.render-after` | 支払い方法の直後 |

**典型的なユースケース：**

- 決済ページへのカスタムバナー表示
- 法的同意チェックボックスの追加
- 配送日時指定フォームの追加
- Thank you・Order Status ページの拡張

```typescript
// extensions/checkout-ui/src/index.tsx
import {
  reactExtension, useCartLines, Text, BlockStack,
} from "@shopify/ui-extensions-react/checkout";

export default reactExtension("purchase.checkout.block.render", () => <Extension />);

function Extension() {
  const lines = useCartLines();
  const totalItems = lines.reduce((sum, line) => sum + line.quantity, 0);
  return (
    <BlockStack>
      <Text>合計 {totalItems} 点のご注文ありがとうございます</Text>
      <Text appearance="subdued">発送は3〜5営業日を予定しています</Text>
    </BlockStack>
  );
}
```

<u>Checkout Extensibility へできるだけ早期に移行することを Shopify は推奨しています。</u>

> 💡 **Checkout UI Extension を確認してみよう:** Shopify Partner ダッシュボードで「Plus の機能 → Checkout エディタ」を開き、拡張ポイントがどのようにチェックアウト画面にマッピングされるか確認してみましょう。実際に拡張を追加する前に、どこにどんなカスタマイズが入れられるかをビジュアルで把握するのが実装の近道です。

## B2B 機能とカンパニー管理・Multistore の活用

Shopify Plus の **B2B チャネル** は企業間取引に特化した機能セットです。

<mark>「**カンパニー（Company）**」という単位で B2B 顧客を管理し、カンパニーごとに異なる価格リスト・支払い条件・購買担当者の権限設定が可能です。</mark>

**B2B 機能の主要設定項目：**

| 機能 | 内容 |
|---|---|
| 価格リスト | 特定カンパニーにのみ表示される専用価格（固定価格 or 割引率） |
| 支払い条件 | 即時払いではなく「30日後払い」「60日後払い」の請求書払い |
| ドラフト注文からの確定 | B2B 担当者が見積もりを作成し、購買担当者が承認して注文確定 |
| 購買承認フロー | カンパニー内の役割（Admin / Ordering / None）に応じた権限管理 |

**Multistore（Organization）：**

1つの Plus 契約で複数のストアを一元管理できます。本番ストア・開発ストア・地域別ストア（日本・北米・欧州）などをまとめて管理でき、Organization 全体のレポートで売上サマリーを確認できます。

<u>B2B 展開を始める前に「カンパニーごとの価格リスト管理」「請求書払いのフロー」「購買担当者の権限設計」を設計してから実装に入ることで、後から設定を大幅に変更するコストを避けられます。</u>

> 💡 **B2B 機能の導入可否を確認してみよう:** 自社のビジネスに「特定の法人顧客にだけ卸売価格を適用したい」「30日後払いで受注したい」「複数の購買担当者が同じカンパニーアカウントで注文したい」のいずれかの要件があれば、Shopify Plus の B2B 機能が直接解決策になります。要件を整理して、Plus 移行の費用対効果を確認してみましょう。

## よくある質問

**Q. 月商 500 万円程度ですが、Shopify Plus は必要ですか？**

その売上規模では Plus の費用対効果が出にくいです。<u>Plus が本当に必要なのは「B2B 取引のカンパニー管理が必要」「チェックアウトをカスタマイズしないと法的・業務的な要件が満たせない」「月商が 1,000 万円を超えてトランザクション手数料の削減コスパが合う」などの条件が揃った場合です。</u>

**Q. 旧 `checkout.liquid` を使っているストアは今すぐ移行しなければなりませんか？**

廃止期限を過ぎた後も当面は動作しますが、Shopify からの新しいチェックアウト機能が自動適用されなくなります。<u>移行の優先度は「checkout.liquid に何をどれだけカスタマイズしているか」によって変わります。Checkout Extensibility へできるだけ早期に移行することを Shopify は推奨しています。</u>
