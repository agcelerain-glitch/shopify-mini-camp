## 在庫アラートと欠品防止の運用設計

在庫切れは売上機会の損失だけでなく、SEO 的にも「在庫切れ商品ページが長期間存在する」という問題を引き起こします。Shopify では各商品のバリアントごとに「**在庫が少なくなったときに通知する**」設定があり、在庫数が指定の閾値（たとえば5個）を下回ったときにメール通知を受け取れます。この設定は商品のバリアント編集画面の「**在庫の追跡**」セクションで行います。ただし Shopify 標準の通知は1商品ずつの手動設定が必要で、商品数が多い場合には **Stocky**（Shopify 公式の在庫管理アプリ）や在庫管理 SaaS（Zaiko Robot・CROSS MALL・ネクストエンジンなど）との連携を検討してください。<mark>在庫管理で特に重要なのは「**安全在庫**」の考え方です。安全在庫とは「発注してから入荷するまでのリードタイム中に予想される需要をカバーする在庫数の最低ライン」で、リードタイムが 7 日・1日平均販売数が 3 個なら最低 **21 個**を安全在庫として設定し、それを下回ったら発注するルールにします。</mark>セール・季節需要・SNS でのバズなど突発的な需要増加も考慮して、余裕を持った安全在庫設定が欠品リスクを大幅に下げます。

> 💡 **在庫アラートを設定してみよう:** 任意の商品を開き、バリアントをクリックして「在庫の追跡」セクションの「在庫が少なくなったときに通知する」をオンにして閾値（例：5）を入力しましょう。設定後、その商品の在庫を手動で閾値以下に変更すると通知メールが届くことを確認できます。

## 複数ロケーションでの在庫分散管理

**ロケーション**は Shopify において在庫の保管場所を管理する単位で、複数の倉庫・実店舗・外部フルフィルメントセンターを別々に管理できます。管理画面「**設定 → ロケーション**」で追加し、各商品のバリアントに対してロケーション別の在庫数を設定します。たとえば「東京倉庫：50個」「大阪実店舗：20個」「EC 専用在庫：100個」というように分けて管理できます。<mark>**注文が入った際にどのロケーションからフルフィルメントするか**は手動で選択するか、ロケーションの優先順位設定に従って自動で決定されます。「在庫があるロケーションを優先」「特定のロケーションを常に最優先」などのルールを設定できます。</mark>ロケーション管理のメリットは「店舗在庫と EC 在庫を分けて管理しながら、EC 注文に対して店舗在庫を使うこともできる」柔軟性です。ただし、複数拠点での複雑な在庫移動管理・ロット管理・賞味期限管理が必要な食品・製薬系ビジネスでは<u>外部の WMS（倉庫管理システム）との連携が現実的</u>です。Shopify は API 経由でほぼすべての在庫データを読み書きできるため、外部システムとのリアルタイム在庫同期が技術的に可能です。

## Shopify の仕入れ注文機能と入荷管理

Shopify には**仕入れ注文（Purchase Orders）** 機能があり、仕入れ先（サプライヤー）への発注と入荷管理を管理画面内で行えます。管理画面「**在庫 → 仕入れ注文**」から新しい発注書を作成し、仕入れ先・商品・数量・コスト・予定入荷日を記録します。発注書の PDF を印刷してサプライヤーに送付したり、メールで送信したりすることもできます。商品が入荷したら発注書を開いて「**入荷済みとしてマーク**」を実行し、実際の入荷数量を入力すると在庫が自動で加算されます。<mark>仕入れコストを記録することで商品ごとの仕入れ原価管理ができ、Shopify Analytics の「**利益**」レポート（Advanced 以上）では売上から仕入れコストを差し引いた**粗利**が確認できます。粗利管理は値付け戦略・セール施策・送料の設定判断に不可欠です。</mark><u>仕入れコストを正確に入力する習慣をつけることが財務の健全性につながります。</u>商品数・仕入れ先・発注頻度が増えてきたら、Shopify の仕入れ注文機能だけでは限界が来ることがあり、そのタイミングで在庫管理・仕入れ管理専用ツールへの移行を検討するのが現実的です。

> 💡 **仕入れ注文を作ってみよう:** 管理画面「**在庫 → 仕入れ注文 → 仕入れ注文を作成**」から、仕入れ先（supplier）と商品を選択して発注書を作成してみましょう。PDF でダウンロードして内容を確認し、入荷後に「入荷済みとしてマーク」を実行して在庫が自動加算されるフローを体験してください。
