## Online Store 2.0 アーキテクチャの全体像

Shopify は 2021 年に「**Online Store 2.0**」と呼ばれるテーマシステムの大規模刷新を行いました。<mark>最大の変更点は、テンプレートが Liquid ファイルから **JSON ファイルへ移行**したことです。旧来の `product.liquid` では Liquid コードに直接 HTML を書いていましたが、新しい `product.json` はどのセクションをどの順序で配置するかを定義するだけで、実際のコンテンツ表示はセクションに委ねます。この変更によりマーチャントが**テーマエディタでほぼすべてのページのレイアウトをドラッグ＆ドロップで変更**できるようになりました。</mark>Dawn をはじめとする Shopify 公式テーマはすべてこのアーキテクチャを採用しています。

Shopify CLI でテーマを操作するには `shopify theme dev` でローカルプレビューを立ち上げ、`shopify theme push` で変更をストアに反映します。テーマファイルは GitHub 等のバージョン管理と相性がよく、ブランチごとに異なるデザインを試して、本番には `main` ブランチのみを反映するという運用が可能です。<u>テーマを直接 Shopify Admin の「オンラインストア → テーマ → コードを編集」から変更することもできますが、誤操作でファイルを壊すリスクがあるため、開発時はローカルで作業してプッシュする方法を強く推奨します。</u>

> 💡 **テーマのファイル構造を確認してみよう:** 管理画面「**オンラインストア → テーマ → コードを編集**」を開き、左サイドバーのフォルダ一覧（layout / templates / sections / snippets 等）を確認してみましょう。`templates/product.json` を開いて、どのセクションが定義されているかを確認してください。

## ディレクトリ構成とファイルの役割

テーマのフォルダ構造は以下の8種類に分類されます。

- **`layout/`** — すべてのページが使う HTML の骨格。`theme.liquid` が `<html>`〜`</html>` 全体のラッパーで、`{% content_for_header %}` や `{% content_for_layout %}` という特別なタグで各テンプレートのコンテンツを差し込みます。
- **`templates/`** — どのセクションを配置するかを定義する JSON ファイル群。`product.json`、`collection.json`、`index.json`（トップページ）など URL パターンに対応したファイルが存在します。
- **`sections/`** — 個別のUIコンポーネント。Liquid コードと `{% schema %}` 〜 `{% endschema %}` に囲まれた JSON 設定が一体になっています。
- **`snippets/`** — セクションから `{% render 'card-product' %}` のように呼び出す再利用可能な小パーツ。引数（変数）を渡して動的に使えます。
- **`config/`** — `settings_schema.json`（テーマ設定の定義）と `settings_data.json`（実際の設定値）。テーマエディタの「テーマ設定」タブに表示される内容がここに対応します。
- **`locales/`** — 多言語対応の翻訳ファイル。`ja.json`・`en.json` などを置き、Liquid 内で `{{ 'general.cart.add_to_cart' | t }}` のように参照します。
- **`assets/`** — CSS・JavaScript・画像・フォントなどの静的ファイル。
- **`.github/` / `shopify.theme.toml`** — Theme Check や CI/CD の設定ファイル。

<mark>特に重要な関係は「**テンプレート → セクション → スニペット**」の三層構造です。この階層を理解することが Online Store 2.0 開発の核心です。</mark>

---

## テンプレートとセクションの実際の関係

`templates/product.json` の中身は次のような構造です。`sections` キーの中に各セクションの ID と設定値が格納されており、`order` 配列で表示順序を決定します。

```json
{
  "sections": {
    "main": {
      "type": "main-product",
      "blocks": {
        "title": { "type": "title" },
        "price": { "type": "price" },
        "variant_picker": { "type": "variant_picker" },
        "buy_buttons": { "type": "buy_buttons" }
      },
      "block_order": ["title", "price", "variant_picker", "buy_buttons"]
    },
    "product-recommendations": {
      "type": "product-recommendations"
    }
  },
  "order": ["main", "product-recommendations"]
}
```

<mark>`block_order` に注目してください。`blocks` で定義した各ブロックの表示順をこの配列で制御します。**テーマエディタでブロックをドラッグすると、この `block_order` が書き換わる仕組みです。**</mark>セクション自体は `sections/main-product.liquid` という独立したファイルで定義されており、`{% schema %}` 内の `"blocks"` 配列でどんな種類のブロックが追加可能かを宣言します。<u>この「テンプレートがセクションを組み立て、セクションがブロックを管理する」三層構造が Online Store 2.0 の核心です。</u>

## よくある質問

**Q. `settings_data.json` を直接編集すると何が起きますか？**

テーマエディタで変更した設定値はすべて `settings_data.json` に保存されます。直接編集すること自体は可能ですが、<u>JSON の文法ミス（末尾のカンマ、クォーテーションの不一致など）があるとテーマが壊れてストアが正常に表示されなくなります。必ずバックアップを取ってから編集し、変更後はテーマのプレビューで動作を確認してください。</u>

**Q. 旧来の `.liquid` テンプレートと `.json` テンプレートの違いは何ですか？**

旧テーマでは `templates/product.liquid` というファイルに HTML と Liquid が直接書かれており、そのファイル自体がページのコンテンツ全体を定義していました。Online Store 2.0 の `.json` テンプレートはセクションの「配置設定ファイル」に過ぎず、コンテンツは各セクションファイルに分散されています。互換性のために現在も `.liquid` テンプレートは動作しますが、テーマエディタでの柔軟なカスタマイズができません。<u>新規テーマ開発や既存テーマの改修では `.json` テンプレートへの移行を強く推奨します。</u>
